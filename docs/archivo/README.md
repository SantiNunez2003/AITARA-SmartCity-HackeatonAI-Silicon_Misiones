# Archivo: versiones anteriores

Los documentos de esta carpeta describen una versión anterior de AITARA, centrada en el despacho táctico de inspectores y en una anticipación de 30 a 60 minutos.

**No son vigentes.** Se conservan solo como historial del proceso de diseño.

La propuesta vigente está en `docs/PROPUESTA_TECNICA.md` y las reglas del proyecto en `PRINCIPIOS.md`.
